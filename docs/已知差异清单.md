# 2025 新宠技能已知差异清单

更新时间：2026-10-29（对应提交 `ec13f30`，后续改动以本文件与 `docs/技能效果表.md` 为准）。

## 一、总体结论

- 119 个技能全部有生效记录：独立脚本 107、精确 12、近似 0、待补 0。
- “独立脚本”表示该技能有独立 `script_700xxx` / `get_combat` 分支，后续可以单独改，不再和别的技能共用模板；**不代表所有数值都来自原服**。
- 客户端 `data_combat_skill` 只有目标模式/目标数/消耗/冷却/档位，`data_skill` 只有文字描述；**没有** `dmg_ratio`、命中上下限、脚本参数、buff 系数。2025 官方服务端包目前没有，所以部分数值只能推断。

## 二、全局性差异

1. **主动伤害倍率**：20 个主动攻击技能的倍率按客户端 f16 档位推断（1200/1300/1400/1600/1800），不是原服精确值。
2. **模糊概率的当前策略**：描述只写“有几率”的按 **50%**；“一定概率/有一定概率/有一定几率”按 **70%**；“极大概率/极大几率”按 **90%**。涉及 60449（90%）、67075（90%）、60450（70%）、67207（70%）、67133（50%）、67200 灼烧（50%）、67378（50%）、67082/67315（70%）等。
3. **DoT / 直接扣血路径**：新增的 `hurt_before` 钩子只覆盖普通攻击、反击、协助攻击；DoT 直接改 HP 不经过 `dmg/6`，因此 67347、67337、67341、67308/67369 的致命判定对 DoT 不生效。
4. **叠层上限**：通用叠层 buff 90500 最大 99 层、90501 最大 3 层；描述写“无限叠加”的实际封顶 99。
5. **表现层**：蛋形、隐身、护盾等只做了战斗机制，没有替换客户端模型/动画资源。
6. **旧脚本冲突规则**：60285/60286 与鬼魂/神佑/逃生的互斥、体质修正等沿用旧 60xxx 脚本，未逐项对照原服。

## 四、建议优先实战验证

1. **蛋形**：20068 亡川的 67369、20053/20057 的 67308。看致命伤害是否变蛋、蛋内再致命是否死亡、下回合是否恢复。
2. **DoT 边界**：67347、67337、67341 在中毒/灼烧/流血等 DoT 致死时不会触发拦截，这是当前引擎路径决定的。
3. **叠层与概率**：67082 牛威、67132 野蛮、67360 扶摇，确认层数和 70%/30%/10% 的触发频率。
4. **额外释放**：67370 叠法、67087 神兵加持、67379 九龙神火，确认不会连锁刷屏。
5. **护盾**：67366/67371 的“挡 6 次”以及 67307 的 CD5 减伤盾。

## 五、精确化所需条件

- 提供 2025 官方服务端包或原服技能数值：可直接替换倍率、概率、buff 系数。
- 只提供客户端资源：需要能从 `data_skill_buff` / `data_buff` 找到对应 buff 数值；目前 70055 等只有名称/描述，没有数值。
- 需要改引擎才能做的项：DoT 致命拦截、首次控制免疫、暴击叠层直到暴击、低血狂暴翻倍、蛋形模型/动画。
