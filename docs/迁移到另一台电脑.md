# 迁移到另一台电脑

目标：在新电脑上运行同一套本地服和游戏，并继续修改。

## 1. 需要手动拷贝的大文件（不进 git）

按相同的相对路径放到项目根目录：

| 路径 | 大小 | 用途 |
|---|---|---|
| `base_icon.apk` | 441 MB | 已打补丁、重签并换过图标的游戏包（安装用） |
| `tmp/erlang19/` | 338 MB | Erlang OTP 19.3 运行时（`start_all.sh` 使用） |
| `tmp/mariadb/mariadb-10.6.28-winx64/` | 256 MB | MariaDB 10.6 运行时 |
| `tools/platform-tools/` | 17 MB | adb |
| `tools/jdk-21.0.12.1+1/` | 329 MB | 只有重新签 APK 时才需要 |
| `tools/7zr.exe` | 1 MB | `local_server/lzma_compress.ps1` 使用 |
| `wsa/WSA_2407.40000.4.0_x64/` | 1.9 GB | 新电脑没装 WSA 时才需要 |

不需要拷贝：

- `YCserver/run/mysql-data`：用 `db/fswy_current.sql` 还原（已含当前角色进度）。
- `extracted/`：`python scripts/extract_assets.py` 从 APK 解出。
- `tmp/bundle_patched/`、`tmp/bundle_2025_patched/`：`dist/` 里已有成品。
- `XYserver/`（另一个游戏）、`rea/`、`rea_out/`、`lua_decoded/`：与运行无关。

可选拷贝：

- `cdn/`（约 158MB）：官方 2025 补丁镜像。不拷也能在首次进游戏时联网从官方 CDN 重新下载；官方 CDN 失效或想离线部署时再拷。

> 如果坚持直接拷 `mysql-data`：先在旧电脑停服（`YCserver/run/stop_all.sh`），再整目录拷贝，并保证两台电脑 MariaDB 版本一致。

## 2. 新电脑前置

1. Windows 11 + WSA：
   - 用安装包：管理员 PowerShell 运行 `wsa\WSA_2407.40000.4.0_x64\Install.ps1`
   - 打开「适用于 Android 的 Windows 子系统」→ 开发者 → 开启「开发人员模式」（ADB）
2. Python 3，并安装依赖：`pip install -r requirements.txt`
3. Git Bash（默认 `C:\Program Files\Git\bin\bash.exe`，启动脚本用）

## 3. 拉代码、放大文件

```bash
git clone <私有仓库地址> D:\moyu\nixiangxiao
```

把第 1 节的大文件按表放好。项目可以放在任意路径：`scripts/prepare_env.ps1` 会把 `env.cfg` 里的旧路径和旧主机名改成当前电脑。唯一要求是 Git Bash 路径固定（脚本里写死 `C:\Program Files\Git\bin\bash.exe`，不同请自行修改 `启动遮天.bat`）。

## 4. 初始化

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File scripts\prepare_env.ps1
powershell -ExecutionPolicy Bypass -File scripts\init_db.ps1
python scripts\extract_assets.py
```

- `prepare_env.ps1`：校验运行时/APK；把 4 个 `env.cfg` 里的 `D:/moyu/nixiangxiao` 和主机名 `cll` 改成当前电脑。
- `init_db.ps1`：初始化 MariaDB 数据目录（root / 123456），启动并导入 `db/fswy_current.sql`。初次或加 `-Force` 才导入。
- `extract_assets.py`：从 `base_icon.apk` 解出 `extracted/assets`（HTTP 服务和 bundle 补丁需要）。

## 5. 启动服务

Git Bash 里执行：

```bash
YCserver/run/start_all.sh      # 4 个 Erlang 节点
YCserver/run/start_http.sh     # HTTP 8081（默认 2025 资源版本，兼官方 CDN 镜像）
YCserver/run/connect_wsa.sh    # adb connect + reverse 8081/8001
```

或者直接双击 `启动遮天.bat`，它会检测并补齐未启动的服务。

HTTP 服务默认 `RES_VERSION=202506251639`、`UPSTREAM_CDN=http://106.52.8.88:81/xcqy_dev`；想换版本或禁用外网，改 `YCserver/run/start_http.sh` 里的环境变量。

## 6. 部署客户端

全新安装分两步。

**6.1 安装并让它更新到 2025**

```powershell
powershell -ExecutionPolicy Bypass -File scripts\deploy_client.ps1
```

依次完成：安装 APK（未安装时）、推送 2025 版 `dist/textures_business.unity3d`、恢复 `client_data` 基底资源、建立 adb reverse、启动游戏。

进游戏后客户端发现远程资源版本是 `202506251639`，会自动下载约 147MB 更新（走本机 HTTP 代理，缓存进 `cdn/`）。等它走完到 2025 版登录界面；首次会自动填 `test123` 并登录。

> 注意：更新会用官方 2025 bundle 覆盖掉刚推的补丁 bundle，所以还要做 6.2。重新安装 APK 用 `-Reinstall`。

**6.2 推回本地补丁 bundle**

关掉游戏（或直接执行，脚本用临时文件中转，不需要停游戏）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\deploy_client.ps1 -BundleOnly
```

把 `dist/textures_business.unity3d` 和 `dist/textures_business_data.unity3d` 一起推到 `res`/`res_theone`，不动其它资源；重启游戏生效。

## 7. 验证

- 登录界面选择「本地测试服」→ 进入世界（2025 版 UI，圣心城）。
- 点右上角宠物头像 → 宠物面板 → 右侧「图鉴」→「特殊宠物」：共 95 只可见，20022–20069（含 20041 天门战神、20046 枭、20051 玉兔等 26 只 2025 新宠）排在最前，不需要滑到底。
- 服务端已包含新宠数据与技能（`pet_data`/`skill_data`/`skill_combat_data` 的 beam 和 `erl_src` 都已提交），克隆下来即可用，不需要再跑补丁脚本。
- 若弹「下载base_setting信息失败」：adb reverse 丢了，重跑 `YCserver/run/connect_wsa.sh` 后点确定。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| WSA 重启后连不上 / base_setting 失败 | `YCserver/run/connect_wsa.sh` |
| `adb devices` 里没有 127.0.0.1:58526 | 启动 WSA，确认开发者模式；`adb connect 127.0.0.1:58526` |
| Erlang 节点不足 4 个 | 看 `YCserver/run/*.out` 日志；确认 MariaDB 先起来 |
| 端口冲突 | 3306 / 8001 / 8081 不能被占用 |
| 主机名变了 | 重跑 `scripts/prepare_env.ps1` |
| 卡在「检查游戏版本」 | 设备 `files/res_theone/base_setting.json` 里 `check_apk` 必须是 `"false"`（服务端默认已保证）；必要时手动改成 false 后重启游戏 |
| 更新卡住 / 停在某个百分比 | 官方 CDN 偶发 502；等本机代理重试，或把 `cdn/` 整个拷来后重启游戏重试 |
| 2025 更新后图鉴/登录补丁失效 | 官方包覆盖了 bundle，执行 6.2 重推 |
| 客户端资源异常 | 重跑 `scripts/deploy_client.ps1`（会恢复到 2021 基底，需要再走一次更新） |
